# Sabores do Brasil 🇧🇷

Site institucional/e-commerce em desenvolvimento para a **Sabores do Brasil**, loja online de produtos brasileiros em Portugal.

## Estrutura

- `index.html` — página inicial
- `produtos.html` — catálogo e categorias
- `novidades.html` — novidades
- `promocoes.html` — promoções
- `sobre.html` — sobre a empresa
- `faq.html` — perguntas frequentes
- `contactos.html` — contactos e formulário
- `carrinho.html` — carrinho de demonstração
- `conta.html` — área de cliente (estrutura inicial)
- `favoritos.html` — favoritos (estrutura inicial)
- `politica-privacidade.html` — política de privacidade
- `termos-condicoes.html` — termos e condições
- `css/style.css` — design e responsividade
- `js/main.js` — interações básicas e carrinho local

## Publicação

O projeto foi preparado para ser publicado com GitHub Pages.

Antes de usar comercialmente, preencher os dados legais da empresa, preços, produtos, métodos de pagamento, portes, transportadora, contactos e demais informações reais.
